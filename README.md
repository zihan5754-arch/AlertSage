# AlertSage

面向蓝队防守人员的告警智能研判助手。

## 功能

- 输入原始告警（JSON）
- 输出攻击类型、危害评级、误报可能性、处置建议
- 当前版本：基于正则规则的快速研判
- 规划中：接入 LLM 做语义分析与处置建议生成

## 快速开始

```bash
pip install -r requirements.txt
uvicorn app.main:app --reload
```

打开 http://127.0.0.1:8000/docs 查看接口文档。

## 项目背景

源自 2026 年 8 月护网蓝队实战经历：告警量大、重复研判多、误报率高。
目标是用规则 + LLM 辅助分析师做初步研判，把精力留给复杂攻击。
